World & sets

Path: /etc/portage/world. Every explicitly installed package is added automatically and removed on unmerge. One package per line; optional repo prefix:

cachyos-extra-v3/rust-analyzer
aur/ayugram-desktop-bin
abs/nano-custom
extra/firefox
Err/local-thing

Prefixes: official repo name, aur/, abs/, Err/ (source unknown).

Two meanings of @world

  • emerge @world (no -u) — provision: install whatever world lists that isn’t already on the system.
  • emerge -u @world (or emerge -u) — upgrade: upgrade everything already installed. Does not read world.
  • emerge --sync — database refresh only.

Custom sets

/etc/portage/sets/<name>.set → @<name>. One atom per line, # comments allowed. Combine freely:

emerge @game-kit @dev-tools neovim
emerge --list-sets

--regen-world / --regen-sets @name re-resolve repo prefixes. Add --regen-sort to alphabetize a set (drops comments/grouping).

Шлях: /etc/portage/world. Кожен явно встановлений пакунок додається автоматично, при видаленні — прибирається. Один пакунок на рядок; опційний префікс репо.

cachyos-extra-v3/rust-analyzer
aur/ayugram-desktop-bin
abs/nano-custom
extra/firefox
Err/local-thing

Два значення @world

  • emerge @world (без -u) — провізіювання: встановити відсутнє з world.
  • emerge -u @world — оновлення: оновити все встановлене. World не читається.
  • emerge --sync — лише освіження баз.

Власні набори

/etc/portage/sets/<name>.set → @<name>. Один атом на рядок, #-коментарі дозволені.

emerge @game-kit @dev-tools neovim
emerge --list-sets

make.conf

/etc/portage/make.conf and ~/.config/emerge/make.conf — aura-emerge’s own config (not makepkg.conf). System first, user last; last key wins.

EMERGE_DEFAULT_OPTS="--pkgbuild-view --unshare-net-build"

CFLAGS="-march=native -O2 -pipe"
CXXFLAGS="$CFLAGS"
RUSTFLAGS="-C target-cpu=native"
MAKEFLAGS="-j$(nproc)"
OPTIONS=(strip docs !debug lto)
BUILDENV=(!distcc color check !sign)

Build flags are applied via a generated makepkg.conf passed to makepkg --config. Values are shell-expanded, so -j$(nproc) and CXXFLAGS="$CFLAGS" work. EMERGE_DEFAULT_OPTS only accepts an allowlist of modifier flags — not actions like --unmerge.

Conflicting pairs (--aur/--abs, --no-sandbox/--unshare-net-build, …) are rejected or the config side is dropped when the CLI is more specific. --ignore-default-opts skips defaults for one run. emerge --info shows loaded files and expanded values.

/etc/portage/make.conf і ~/.config/emerge/make.conf — конфіг самого aura-emerge (не makepkg.conf). Системний файл першим, користувацький останнім.

EMERGE_DEFAULT_OPTS="--pkgbuild-view --unshare-net-build"

CFLAGS="-march=native -O2 -pipe"
CXXFLAGS="$CFLAGS"
RUSTFLAGS="-C target-cpu=native"
MAKEFLAGS="-j$(nproc)"
OPTIONS=(strip docs !debug lto)
BUILDENV=(!distcc color check !sign)

Прапори збірки застосовуються через згенерований makepkg.conf. EMERGE_DEFAULT_OPTS приймає лише allowlist модифікаторів. --ignore-default-opts — один запуск без дефолтів.

package.mask

/etc/portage/package.mask — file or directory of files. Hard stop: never install, even as a transitive AUR dependency or by explicit name. Not a prompt.

ayugram-desktop-bin            # any source
aur/*-bin                      # never AUR -bin
*-git                          # no devel on this box
extra/nano                     # specific repo/name

Optional trailing # reason is shown when the mask fires. Separate from one-run --exclude.

Жорстка зупинка: ніколи не встановлювати, навіть як транзитну AUR-залежність. Не запит, а відмова.

ayugram-desktop-bin
aur/*-bin
*-git
extra/nano

--exclude / --keep-going

--exclude <atom> (repeatable or comma-separated) leaves a package out of the current run — installs, -u, @world, depclean/prune, revdep.

emerge -u --exclude linux --exclude aur/ayugram-desktop-bin
emerge --exclude firefox @world

--keep-going does not stop a batch at the first failure; collects failures and prints a summary with non-zero exit. --resume after that retries only the failed packages.

--exclude виключає пакунок з поточного запуску. --keep-going не зупиняє пакетну операцію на першій помилці — збирає підсумок і ненульовий код виходу. --resume після цього повторює лише те, що впало.

-t / --tree, --deep

Shows the plan as a dependency tree (emerge -pt-style). Default: one level of nesting. --deep nests the full chain; --deep=N caps at N levels.

emerge -apt noctalia --aur
emerge -pt noctalia --aur --deep
emerge deepin-session --ask --tree --deep=3

План як дерево залежностей. За замовчуванням один рівень. --deep — увесь ланцюг; --deep=N — обмеження глибини.

Merge / unmerge log

/var/log/emerge.log — append-only, one line per event. AUR/ABS get real per-package duration; pacman batches share one total. emerge --info shows cumulative stats.

2026-09-21 08:51:44  MERGE    aur    noctalia-5.1.0-1.1        (12s)
2026-09-21 09:03:02  MERGE    repo   nano-8.0-1  vim-9.1-1     (4s)
2026-09-21 09:10:05  UNMERGE  -      old-package-2.0-1

/var/log/emerge.log — append-only. AUR/ABS мають реальну тривалість на пакунок. emerge --info показує накопичену статистику.

Usage highlights

emerge neovim                              # repos → AUR fallback
emerge neovim-git --aur                    # AUR only, recursive AUR deps
emerge neovim --abs                        # ABS in bwrap
emerge -u @world                           # full upgrade (does not read world)
emerge @world                              # provision from world
emerge --scan neovim-git --aur             # audit only
emerge --install-pkgbuild ~/src/my-pkg     # local PKGBUILD (scanner + sandbox)
emerge -u --devel                          # upgrade + rebuild moved -git
emerge --revdep-rebuild                    # broken shared-library links
emerge --batchinstall pkgs.txt             # mass-install from list
emerge --news                              # Arch news
emerge --undo                              # undo last install/unmerge
emerge --resume                            # resume interrupted run

bwrap sandbox

AUR/ABS run pkgver/prepare/build/check/package inside bubblewrap when installed:

  • Fake $HOME (no SSH/GPG secrets, no browser profile)
  • Write only inside the build dir (+ configured DEST dirs)
  • Network shared by default; --unshare-net-build cuts net for build/check/package
  • Other namespaces torn down; fakeroot in a nested uid-0-mapped layer

Dependency install and final pacman -U stay outside the sandbox.

FlagEffect
--no-sandboxPlain makepkg (warning)
--unshare-net-buildNo network during build()/check()/package()

AUR/ABS виконують функції PKGBUILD у просторі імен bubblewrap: фейковий $HOME, запис лише в директорію збірки, опційна ізоляція мережі. Залежності і pacman -U — поза пісочницею.

Security: PKGBUILD scanner

Before every AUR install, PKGBUILD + .install are fetched from cgit and scanned:

  1. AST (tree-sitter-bash) — curl|sh, decode pipes, process subst, eval "$(curl …)", sudo/pkexec/doas, python inline-exec, shell -c payloads, top-level command substitution, concatenation evasions.
  2. Line heuristics — chmod 777, raw IPv4, foreign package managers, paste sites, .onion, anti-sandbox probes, known IOCs (Atomic Arch, openconnect-sso, 2018 compromised.txt, …).

Findings: Suspicious or ConfirmedIoc. Not a hard block — file/line, cgit link, Continue anyway? [y/N].

emerge --scan neovim-git --aur
emerge --install-pkgbuild ~/src/my-pkg --scan

Два шари: AST (tree-sitter-bash) і текстові евристики. Знахідки — Suspicious або ConfirmedIoc. Не жорстке блокування: запит Continue anyway? [y/N].

emerge --scan neovim-git --aur
emerge --install-pkgbuild ~/src/my-pkg --scan

PKGBUILD review

--pkgbuild-view shows/diffs the PKGBUILD before build and asks for confirmation (offers $EDITOR on decline). Combines with --edit. Only for directly requested packages — not recursive deps or batch paths.

--install-pkgbuild <PATH> builds a local checkout through the same scanner + sandbox pipeline. Recorded in world as Err/ unless -1.

--pkgbuild-view показує/diff PKGBUILD і просить підтвердження. --install-pkgbuild — локальний checkout через сканер + пісочницю.

Devel upstream check

AUR page versions for -git/-hg/… often lag real upstream. --devel (with -u) and --check-devel (report-only) parse git+ URLs from PKGBUILDs and git ls-remote against them.

emerge -u --devel
emerge --check-devel

--devel (з -u) і --check-devel порівнюють git ls-remote з останнім відомим хешем для -git/-hg/…

--revdep-rebuild

Reads installed ELF files (DT_NEEDED, RPATH/RUNPATH) and finds binaries linking against a missing .so — different from @preserved-rebuild, which only checks declared deps via pacman -T.

Foreign packages are rebuilt through the sandboxed path; official packages get missing libraries looked up via pacman -F.

emerge --revdep-rebuild
emerge --revdep-rebuild -p

Читає ELF напряму і знаходить бінарники з битими лінками бібліотек — не те саме, що @preserved-rebuild.
