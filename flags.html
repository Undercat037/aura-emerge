CLI flags

Every flag accepted by emerge — actions, modifiers, Gentoo-compat no-ops, and generated completions/man page.

The emerge(1) man page is generated from the same CLI definition via clap_mangen (emerge --gen-manpage), so it cannot drift from --help.

Man-сторінка emerge(1) генерується з того ж визначення CLI через clap_mangen (emerge --gen-manpage), тож не розходиться з --help.

Страница руководства emerge(1) генерируется из того же определения CLI через clap_mangen (emerge --gen-manpage), поэтому не может разойтись с --help.

Shell completion: bash, zsh and fish are supported. The completions are generated from the CLI (emerge --gen-completions bash|zsh|fish) and installed by the package; emerge @<TAB> offers real set names. The eselect shim has its own hand-written completions (misc/eselect.bash-completion, misc/_eselect, misc/eselect.fish).

Автодоповнення оболонки: підтримуються bash, zsh і fish. Доповнення генеруються з CLI (emerge --gen-completions bash|zsh|fish) і ставляться пакунком; emerge @<TAB> пропонує справжні назви наборів. Shim eselect має власні рукописні доповнення (misc/eselect.bash-completion, misc/_eselect, misc/eselect.fish).

Автодополнение оболочки: поддерживаются bash, zsh и fish. Дополнения генерируются из CLI (emerge --gen-completions bash|zsh|fish) и ставятся пакетом; emerge @<TAB> предлагает настоящие имена наборов. Shim eselect имеет собственные рукописные дополнения (misc/eselect.bash-completion, misc/_eselect, misc/eselect.fish).
